# Gemini AI Image Generation Setup

This guide explains how to set up Gemini AI (NanoBanana) for image generation in your Agentify application.

## Prerequisites

1. A Google Cloud account
2. Access to Google AI Studio
3. Your Supabase project configured

## Step 1: Get Your Gemini API Key

1. Go to [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the generated API key

## Step 2: Configure Backend (Supabase)

Set your Gemini API key as a Supabase secret:

```bash
supabase secrets set GEMINI_API_KEY=your_gemini_api_key_here
```

## Step 3: Configure Frontend (Optional)

If you want to use Gemini for other features (like voice agent AI responses), also set the frontend environment variable:

```bash
# In your .env file
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```

## Step 4: Test the Integration

1. Go to the AI Image Generator page
2. Select "Gemini (NanoBanana)" as your AI model
3. Enter a prompt like "A futuristic cityscape at sunset"
4. Click "Generate Image"

### Image Generation
- **Model**: Gemini 2.0 Flash Experimental
- **Format**: PNG images
- **Safety**: Built-in content filtering
- **Quality**: High-resolution images

### Supported Prompts
- Natural language descriptions
- Style specifications
- Composition requests
- Creative concepts

## Troubleshooting

### Common Issues

1. **"Gemini API key not configured"**
   - Ensure you've set the `GEMINI_API_KEY` secret in Supabase
   - Redeploy your Supabase functions

2. **"No image generated by Gemini"**
   - Check if your prompt violates content policies
   - Try a different, more descriptive prompt
   - Ensure your API key has the correct permissions

3. **Rate limiting**
   - Gemini has usage limits based on your Google Cloud billing
   - Check your quota in Google AI Studio

### API Limits

- **Free tier**: Limited requests per day
- **Paid tier**: Higher limits based on usage
- **Rate limits**: Vary by model and region

## Advanced Configuration

### Custom Safety Settings

You can modify the safety settings in `supabase/functions/generate-image/index.ts`:

```typescript
safetySettings: [
  {
    category: "HARM_CATEGORY_HARASSMENT",
    threshold: "BLOCK_MEDIUM_AND_ABOVE" // or BLOCK_LOW_AND_ABOVE, BLOCK_NONE
  }
]
```

### Generation Parameters

Adjust the generation config for different results:

```typescript
generationConfig: {
  temperature: 0.7,    // 0.0 to 1.0 (creativity)
  topK: 40,           // 1 to 100 (diversity)
  topP: 0.95,          // 0.0 to 1.0 (nucleus sampling)
  maxOutputTokens: 2048 // Maximum tokens
}
```
